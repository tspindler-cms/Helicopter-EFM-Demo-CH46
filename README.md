# CH-46D 0.1.12C source candidate

Editable source for the existing local tandem-rotor CH-46D EFM, its matching DLL,
build entry point, regression checks and eight selectable saved liveries.

Read [source/build/install instructions](README_CH46D_0.1.12C.md) and
[validation results](docs/SOURCE_VALIDATION.json). DCS runtime validation remains pending.
The inherited engine curves and gauge calibration remain provisional.

This review branch is based on `ch46d-slow`; it does not replace that branch.
Original upstream history and credits are preserved in [UPSTREAM_README.md](docs/UPSTREAM_README.md).
