# CH-46D EFM 0.1.12C

Focused fix: external rotor-droop animation argument conflict.

- Changed `EXT_RotorDroop` from external animation argument 36 to 1036.
- Argument 36 remains available to the model's ramp animation, removing the
  conflict that prevented the ramp from closing.
- Retains all 0.1.12B governor and 0.1.12A handling changes unchanged.
- No flight physics, geometry, cockpit, HUD, or Lua behavior changed.

The EDM must define rotor-droop animation argument 1036 for the visual effect to
remain visible. Ramp closure and rotor droop both require DCS validation.
